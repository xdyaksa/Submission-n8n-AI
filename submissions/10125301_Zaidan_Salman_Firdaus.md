## 💡 Ringkasan & Solusi Otomasi (Workflow Highlights)

- **Tujuan Workflow**: Membangun *workflow* otomasi dasar di n8n untuk memahami konsep kerja *trigger*, pemrosesan data sederhana, dan pengiriman *output* secara otomatis tanpa intervensi manual.
- **Node Kunci yang Digunakan**: Manual Trigger / Schedule Trigger, Edit Fields (Set), HTTP Request, dan Output Notification Node.
- **Logika Alur Kerja**: 
  1. *Workflow* dipicu (*triggered*) secara manual atau terjadwal saat dijalankan.
  2. Data masukan diproses dan disesuaikan nilainya menggunakan node pengolah data (seperti Edit Fields / Set).
  3. Data yang sudah rapi lalu diteruskan ke node tujuan (misal pengiriman pesan/API) sampai eksekusi statusnya berhasil (*success*).
