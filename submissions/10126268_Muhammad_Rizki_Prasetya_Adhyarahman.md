## 💡 Ringkasan & Solusi Otomasi (Workflow Highlights)
Tuliskan penjelasan singkat mengenai alur kerja yang telah kamu bangun:
- **Tujuan Workflow**: Alur otomatisasi di n8n yang berfungsi sebagai API berbasis kecerdasan buatan (AI) untuk memproses data masuk dan mengirimkan balasannya secara otomatisi latar belakang tanpa perlu intervensi manusia, sehingga mengurangi risiko keterlambatan respons atau *human error*.
- **Node Kunci yang Digunakan**: Webhook, Edit Fields, Message a Model, Respond to Webhook
- **Logika Alur Kerja**: Alur kerja ini dimulai saat node Webhook menerima data masuk melalui permintaan HTTP POST dari aplikasi luar, lalu meneruskannya ke node Edit Fields untuk disaring dan dirapikan formatnya. Data yang sudah bersih kemudian dikirim ke model AI Google Gemini pada node Message a model untuk dianalisis menjadi sebuah jawaban, yang akhirnya langsung dikembalikan kepada pengirim awal melalui node Respond to Webhook.
